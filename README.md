## GitHub Pages-ке орнату (қазақша)

1. github.com сайтына кіріңіз → жоғары оң жақта **+** → **New repository**.
2. Атауын жазыңыз, мысалы `ustaz-prompt`. **Public** таңдаңыз → **Create repository**.
3. Ашылған бетте **uploading an existing file** сілтемесін басыңыз.
4. Архивті компьютерде ашып, `ustaz-prompt` папкасының **ішіндегі** барлық файлды (`index.html`, `favicon.svg`, `README.md`, `LICENSE.txt`, `.nojekyll`) терезеге сүйреп салыңыз → **Commit changes**.
   `.nojekyll` файлы көрінбесе — ол міндетті емес, сайт онсыз да жұмыс істейді.
5. **Settings** → сол жақта **Pages** → *Build and deployment* бөлімінде **Source: Deploy from a branch**, **Branch: main**, папка **/(root)** → **Save**.
6. 1–3 минуттан кейін сол бетте сілтеме шығады: `https://ЛОГИНІҢІЗ.github.io/ustaz-prompt/`.

**Жаңарту:** репозиторийде `index.html` → қарындаш белгісі емес, **Add file → Upload files** арқылы жаңа `index.html` жүктеп, **Commit changes** басыңыз. Сайт 1–3 минутта жаңарады.

**Компьютерде ашу:** `index.html` файлын екі рет басыңыз — Chrome не Edge-те ашылады. Қаріптер үшін ғана интернет керек.

## Установка на GitHub Pages (по-русски)

1. github.com → **+** → **New repository** → имя, например `ustaz-prompt`, тип **Public** → **Create repository**.
2. **uploading an existing file** → перетащите все файлы из папки `ustaz-prompt` (не саму папку) → **Commit changes**.
3. **Settings → Pages** → **Deploy from a branch**, ветка **main**, папка **/(root)** → **Save**.
4. Через 1–3 минуты появится адрес `https://ВАШ-ЛОГИН.github.io/ustaz-prompt/`.

## Что важно знать

- Всё работает в одном файле `index.html`, без сервера и базы данных.
- Избранное, черновик научного проекта и правки в режиме администратора хранятся только в браузере пользователя. Для переноса есть «Резервная копия» (в библиотеке) и «Черновик» (в научном проекте).
- Персональные данные учеников в платформу и в ИИ не вводятся.
- Тарифы и функции сервисов в библиотеке проверены на 26–27.09.2026; перед использованием сверяйте с официальными сайтами.
